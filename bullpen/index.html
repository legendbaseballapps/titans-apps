This is a read-out, not a form. The roster ships with the app, released by the program, so every iPad and every app is looking at the same list of players with the same IDs. A name spelled one way here is spelled that way in every export, which is the only reason a season of files can be stacked up and counted.

Wrong, missing or a class that needs moving up? Tell Jim — he releases a corrected roster with the next update. Nothing you charted is affected: a session keeps the name it was charted under.
