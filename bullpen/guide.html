Bullpen Chart Coach's Guide

How to run a winter bullpen on the iPad. The script goes in before anybody warms up; after that it's one tap a pitch.

App v34  ·  October 2026  ·  Winter workouts

What it does

  • Holds the script — the wind-up/stretch/slide step, the pitch, the target location and the situation — so every pitcher on your mound throws the same routine.
  • Records where each pitch actually finished, and works out whether he hit the spot, whether he was close, and whether it was a strike either way.
  • Tells you the pattern in his misses, not just the percentage.
  • Ranks the pitchers on your iPad against each other. Same script, same targets, so the numbers actually compare.
  • Sends every filed session to the coaching dashboard on its own, the next time the iPad has signal. Nobody has to export anything.
  • Still exports a spreadsheet file, as a backup or for anyone who wants the raw rows.
Before you start

It keeps every session you file. Tapping Finish & file this session moves the current one into History and starts a clean one with the same script and the same names — nothing is erased, and the session waits in History until it has reached the dashboard.

Getting it on the iPad

Do this at home, on wifi. Once it is on the home screen it opens with no signal at all — which is the point, because the gym has none.

  • Open legendbaseballapps.github.io/titans-apps in Safari. Not Chrome, and not the browser inside Messages or Mail — if it opens in one of those, tap the compass icon to send it to Safari.
  • Tap Bullpen Chart.
  • Wait for the green bar that says “Ready to use offline.” That is the app telling you it has saved a copy. Don't skip it.
  • Share → Add to Home Screen. Name it Bullpen. You get the Titans zone icon.
  • Prove it: turn on Airplane Mode, close Safari, tap the new icon. It should open normally.
  • Settings → Display & Brightness → Auto-Lock → Never.
  • Use it in landscape. The page scrolls up and down, never sideways.
  • Every iPad needs its own copy. Four iPads, four sessions, four files at the end.
Which version am I on?

The build is printed in the header, next to “Legend Titans · winter workouts.” This guide describes v34. If it shows two numbers in amber, like v9 ≠ v8, that iPad downloaded an update but is still showing the old one — see below.

Getting a new version

You set the icon up once. It never has to be replaced — the app replaces itself underneath it.

  1. Open the app once on wifi. The new copy downloads quietly in the background; the screen still shows the old one.
  2. Close it completely from the app switcher — swipe up, then flick the app away.
  3. Open it again. New version. Check the build in the header.
Don't delete the icon and add it back

That is the one way to lose data. On iOS, removing a home-screen app can take its saved session with it — a session that has not reached the dashboard yet would be gone. The two steps above are all an update needs. If you ever do have to remove it, open it on wifi first and check that History says Every filed session is on the dashboard.

Setting up, before anybody throws

All of this lives on the Setup tab. A new iPad opens empty — load this week’s routine, put in your four or five arms, and go. After that, Finish & file this session starts the next one for you and keeps the script and the names. At the bottom of Setup there is a Reset this session button for when the iPad got set up wrong — it wipes the script, the names and anything charted, keeps the mound name, and never touches sessions already in History. To end a real session use Finish & file, not Reset.

  • Mound — name it so it's different from the other iPads: Mound 1, Mound 2, and so on. This goes into every row of the export and is what keeps the four files apart when they're merged.
  • Date and Coach — who's charting.
  • The script — either load a template (see below) or build it by hand: + Add pitch, then + Repeat last to add four of the same call in a row quickly. Each row is a delivery (W wind-up, S stretch, SS slide step), a pitch type, a target location, and an optional situation — in that order, left to right.
  • Practice session, new in v32. Tick it when you are training a new charter or just trying the app out. A practice session charts and files like any other, but it never goes to the dashboard, so it can't land in a kid's numbers. A bar on the Chart tab reminds you it's on. It switches itself off when you file, so the next pen is real.
  • Pitchers — 4 or 5 per iPad. Name, jersey, hand, PitchSafe number 0–100, the stretch-only box, and under Runs, whether he follows the script or goes freeform.
  • Ready to chart, new in v34, at the bottom of Setup. It turns green and says what is set, like 4 pitchers · Hitter's Counts · 40 pitches, once there is something to chart. Then tap Start charting. If something is missing, it says what, and the button waits.
Stretch only

Tick it for a pitcher who doesn't throw from the wind-up and every W in the script becomes an S for him. You don't need a second script. Slide-step calls are left alone — a slide step already comes out of the stretch, so he can throw it.

Situations

The situation is a picked list, not a typed note, so the report can group on it later: Runner on 1B, Runner on 2B, 2 strikes, chase, 2-0 O/S strike, or none. Pick it on the script row, or in the Call it panel for a freeform pitcher.

Templates — and why the lock matters

Four mounds only compare to each other if they threw the same routine. That is the whole reason the leaderboard means anything, so the app makes the matching script the easy path and tells on you when it drifts.

  • Load template on the Setup tab picks a named routine and locks the script. Every mound that loads the same one is charting the same thing.
  • Four are shipped, and they run in the order the dropdown lists them. Each name says what that week works:
    Fastball Command (25) — fastball and change-up, wind-up only
    Breaking Ball & Stretch (30) — adds the breaking ball and the stretch
    Holding Runners (35) — adds the slide step
    Hitter’s Counts (40) — adds the change-up off the slide step and a 2-0 breaking ball
    Every call in the first one is still in the fourth — the later routines only add, so a pitcher’s numbers compare week to week against the same test.
  • Getting loose is not in the script. The first charted pitch is one he is trying to execute. Count his warm-up separately.
  • CB covers every breaking ball. A slider guy throws his slider on a CB row — it is too pitcher-specific to script.
  • The bar above the script always says where you stand: Running: Winter Week 1, with an ID next to it. Two iPads showing the same ID ran the same routine. That is the check, and it takes two seconds.
  • Unlock to edit is one tap if you genuinely need to change a call. The bar then turns amber — Modified from Winter Week 1 — and every row of that iPad's export is stamped ScriptModified = Y.
  • Building a script by hand is allowed. It just won't compare to the other mounds, and the bar says so plainly.
Adding a routine to the list

Build it on an iPad, tap Save as template, and it hands you a finished line of text. That line goes into the app's template file — a job for the laptop at home, not the gym. The list ships with the app, so once it is in, every iPad has it without anybody doing anything.

The locations

The Location column on the script row. Same six the pitching coaches call off the paper chart, sitting on the same 5×5 grid the in-game app uses. The middle 9 boxes are the strike zone; the ring around them is off the plate. It's the catcher's view, so In is on the left, Out on the right.

  • All six carry a navy number and a dashed outline, so you can see the whole target set at once.
  • The location the script is calling right now turns orange with a ring around it.
  • Pitch types are the paper chart's numbers: 1 FB, 2 CB, 3 SL, 4 CH, 5 CT.

Charting a pitch

One tap. The app already knows what was called, so all you're adding is where it finished.

1

Read the call

The navy card across the top says it: the delivery, the pitch, the location number and what it means, plus the situation. Little map on the right shows the target.

2

Tap where it finished

One tap on the grid. The pitch is logged and the card rolls to the next one in the script. Nothing else to answer.

3

Velo, if you got it

Slide the number strip under the grid and tap the reading. It goes on the pitch you just logged. Skip it and nothing breaks — averages only use the pitches that have a number. Tapping the same number again clears it.

Late radar reading?

Tap that pitch in the Pitch log on the right to select it, then tap the velo. The label above the strip always names the pitch it's about to write to. Tap the same log chip again to let go and get back to live charting.

Reading the grid

Every pitch leaves a numbered dot in the box where it finished. They stack instead of covering each other, so a finished pen shows you the whole session at a glance.

  • Green — on the spot. Exact box.
  • Amber — one box off in any direction.
  • Red — missed.
  • The number in the dot is the pitch number, so you can follow the order he lost it and whether he got the spot back.
  • Six dots fit in a box. Past that you get a +3 chip; the detail is still in the export.

When it doesn't go to script

  • He threw something else, or you changed your mind: tap Change the call, set the delivery, pitch, location and situation, then Use this call. It changes that one pitch for that one pitcher and marks it off-script in the export. Back to the script undoes it.
  • You want to change it for everybody: go to Setup and edit the script row. Pitchers who haven't got there yet pick it up.
  • He's throwing extra: tap + Extra pitch. It adds a rep past the end of the script and opens the editor so you can say what it was.
  • Wrong box: tap ← Go back to drop the last pitch, or tap that pitch in the log and tap the right box to move it.
  • Wrong pitcher: tap the right one in the strip across the top. Everybody keeps his own place in the script, so you can bounce between mounds mid-routine.

Freeform pitchers

Set a pitcher's Runs column to Freeform on Setup and the script gets out of his way. Everybody else on the iPad keeps running the routine — it's set per pitcher, not per session.

  • His Chart screen grows a Call it panel: the delivery, the pitch, and the location. Tap what you just called, then tap where it finished.
  • Everything sticks. Four sliders down and away in a row is one tap each — you only touch the call panel when something changes.
  • Situation is a free-text box that also sticks. Use it or don't.
  • The navy call card still reads the same, so the screen looks familiar and stays readable from the mound.
  • All the numbers still work. You're still calling a location, so on the spot, spot + close and the miss read all mean exactly what they mean in scripted mode.
  • He's marked freeform on the pitcher strip and on his report card, and every one of his rows carries Mode=Freeform in the export so you can split them out later.
When to use it

A kid coming back from an arm issue who just needs to get loose, a side session with a specific fix in mind, or a pen where you're reacting to what you're seeing instead of working a card. If you find yourself using Change the call on every pitch, that pitcher should be freeform.

The roster — released, not typed

On the Setup tab, above the mound list. It ships with the app. You can read it; you cannot change it. The Bullpen Chart and the Offense Chart use the same released roster, so a player is one player across both. The Pitch Chart still types our pitchers free-form — it isn't wired in yet.

Why it stopped being editable. Every export joins on PitcherID. When each iPad kept its own roster, the same kid typed on two iPads got two different IDs, and his winter quietly split into two pitchers the moment the files were stacked up. One released list is the fix. Jim maintains it, each existing ID survives every release, and it arrives with the app update.

  • The banner at the top of the panel says which roster this iPad has: Released roster with the release date is what you want to see. The list of players is folded away — tap Show all … if you want to read it. It opens by itself if anything is wrong with the roster.
  • SAMPLE roster — not the real team in red means the real roster hasn't been released yet and the app is showing placeholders. It will let you chart, which is exactly why it shouts: anything charted against sample players joins up with nothing. Stop and tell Jim.
  • Leftover local roster in amber means this iPad is still showing a list somebody typed into it before releases existed. It still charts fine, but its IDs match nobody else's — get the iPad onto the current version before the next session.
  • Names. A pitcher reads as just his last name. He picks up an initial — Dieker, T — only when somebody else on the roster shares that last name, and his full first name if the initial collides too. Nothing to type; the app works it out. Two Diekers are two separate players with separate IDs.
  • Class — Fr / So / Jr / Sr. This is the field that makes a peer comparison possible: a sophomore measured against sophomores says far more than one measured against the whole program.
  • Throws and Bats are separate. Plenty of kids throw right and hit left, and the Offense Chart needs the bat while the bullpen needs the arm.
  • Moving everyone up a class in June now happens once, when the roster is released — not once per iPad. Graduating seniors come off the roster at the same time; everything they charted stays in the exports, and any session already charted against one keeps his name.
  • A new roster reaches this iPad on its own. You do not need an app update for it — open the app once with signal and it picks up the current roster. If the iPad has no signal it keeps the one it has and the banner says so.
Somebody is wrong, missing, or just graduated

Tell Jim. He releases a corrected roster with the next update, and because the IDs come forward, nothing you have already charted or exported is disturbed — a filed session keeps the name it was charted under.

Picking an arm for the session

The mound list is one picker per slot. His class and throwing hand are printed beside it as a read-out, straight off the released roster.

A kid can only be on one mound slot per session, so a name already picked drops out of the other slots' lists.

Jersey number is gone. A bullpen needs a name; nobody was using the number. The export carries Class, ClassName and Throws where Jersey used to be.

Two ID columns in the export

Every row now carries a SessionID and a PitcherID. You never see them on screen and you never type them — they're there so a merged season of files can be grouped correctly.

A name is not an ID. Two kids share a last name; a spelling gets corrected in February; and a merged file quietly becomes two people or one. The IDs don't change when you fix a name. SessionID does the same job for sessions, because Mound + Date isn't unique — a morning and an afternoon group on the same mound would otherwise merge into one.

Somebody not on the roster

A pitcher charted before rosters were released — or one who has since come off it — keeps his name and stays selectable, marked (not on the roster). Nothing already charted loses its owner.

Switching pitchers

The strip across the top of the Chart tab — Who's throwing — is the switcher. Tap a name and that pitcher's call, log and numbers come up.

  • A pitcher who has finished his card gets a green check beside his name, so you can see at a glance who is done and who still has to throw. No mark means he hasn't finished yet. You can still tap a finished pitcher to look back at his pen.
  • When somebody finishes, his card shows a “Vance is up →” button. Tapping it hands the mound over.
  • And if you just leave the Chart tab and come back, the app moves to the next arm on its own — the first named pitcher with nothing charted yet. Blank rows are skipped; they aren't people until you name them.
  • Tap a name yourself and that choice sticks. Going back to a finished pitcher to look at his zone is deliberate, so tabbing to Report and back won't steer you away from him.
Setting up a pitcher does not put him on screen

Naming a pitcher on Setup doesn't switch the Chart tab to him — you normally set up all four or five arms before anybody throws, and hijacking the screen mid-session would be worse. Tap his name on the strip, or let the hand-off do it when the man ahead of him is done.

Live ABs

Set a pitcher's mode to Live ABs on Setup when he's facing hitters. He gets the same Call it panel as a freeform pitcher, plus an at-bat around it.

  • A big count at the top, worked out from where you plotted the pitches — in the zone is a strike, outside it is a ball. Nothing to enter.
  • A strip of at-bat chips below it. One per AB, with its result and pitch count on it. The live one is outlined.
  • How it ended — the same sixteen results as the Pitch Chart. Tapping one closes the at-bat and opens the next, so the next hitter costs you no extra tap.
  • Tapped the wrong result? Tap that at-bat's chip and tap the right one. A closed at-bat won't take another pitch — it says so rather than quietly appending.
  • + New AB is there for a hitter who never finishes.

The called spot is optional in here

The Location row grows a — no spot called button. Use it when you're competing and nobody called a spot.

Those pitches are left out of the execution numbers, not counted as misses. That matters: a competitive inning where nobody called spots would otherwise look like the worst command of the winter. The pitch still counts for strike %, velo and the at-bat; it just has nothing to be graded against. When some pitches are ungraded the KPI label tells you — Spot · of 12 graded instead of On the spot — and the pip in the zone is outlined instead of coloured.

AO3+

Two characters, the same as the Pitch Chart and the same as the old spreadsheet. The first says whether he got ahead (ahead after three pitches, or the at-bat was over inside three). The second says whether he got the out.

  • ++ ahead, got the out — 2 points
  • +- ahead, no out — 1
  • -+ behind, got the out — 1
  • -- behind, no out — 0

The report shows all four counts, not just a percentage — a pitcher who's losing by never getting ahead is a different problem from one who gets ahead and gets hit, and one number hides which. It needs a result on the at-bat; an open AB isn't counted.

Export: Mode=Live on every row, plus AB, ABResult, ABOut and AO3plus.

What the numbers mean

NumberWhat it counts
On the spotLanded in the exact box that was called. A hard standard on a 5×5 grid — expect it low.
Spot + closeWithin one box of the call. This is the one that'll move week to week.
StrikesFinished in the middle 9, whatever was called. A different question from hitting the spot — a guy can be 20% on the spot and 80% strikes, which tells you he's competitive but not fine.
Miss readThe direction of every miss added up: “9 misses off the spot: 6 up, 4 to the arm side.” That's the coachable part.
Arm side

The miss read says arm side and glove side from a right-hander's point of view, because the grid is fixed. For a lefty, flip it in your head.

End of the session

  • Type your notes into Coach's comments for each pitcher while you still remember what you told him. It's on the Chart tab, under the log.
  • Open the Report tab. The leaderboard at the top ranks everybody on your iPad; each pitcher's card below has his numbers, his miss read and a per-pitch-type breakdown with velo.
  • Then tap Finish & file. That's the step that matters. From v34 it is the orange button in the top right corner, on every tab, as soon as a pitch is charted; when every arm has thrown the whole script, the Chart tab also says Everyone's done and puts the same button in front of you. Either way it asks before it files. It moves the session to History, sends it to the dashboard if there is signal, and hands you a clean sheet with the same script and the same five names, ready for next week.
  • No signal in the gym? Nothing to do. It goes the next time the app opens with signal. See Sending to the dashboard below.
  • Export pitch log (.csv) and Export summary (.txt) are still there, on the Report tab and beside every session in History, for a backup or a page to hand a pitcher. Files are named bullpen-2027-01-21-mound-1.csv, so a winter's worth sorts itself.
  • Every row carries Build, Template, ScriptID and ScriptModified next to the pitch data. Merge the four files and sort on ScriptID — one value means all four mounds ran the same routine, and anything else shows you which one drifted.
File before you leave

The session in progress lives only on this iPad until it is filed. If the iPad gets wiped, cleared or handed to somebody else first, the pen is gone. Filed sessions stay in History.

The red Erase everything button is gone

It was there for testing in the fall. From v32 it is switched off, so nothing on this iPad can wipe History. Reset this session still clears a session that was set up wrong, and never touches History.

Sending to the dashboard

New in v32. Every filed session goes to the coaching dashboard by itself. You don't tap anything, and charting never waits for it.

  • When it sends: the moment you file, and again every time the app opens or comes back to the front with signal. The gym has none, so most pens go out when the iPad next sees wifi.
  • One quiet line on the History tab tells you where things stand: Every filed session is on the dashboard, or 2 sessions waiting to upload.
  • Each session in History has a pill: on dashboard, waiting, or practice (practice never goes).
  • Nothing is lost by waiting. A session stays in History whether it has gone or not, and sending the same one twice is harmless. The dashboard ignores a copy it already has.
If the line turns red

It says the dashboard turned a session away, with the reason. Your sessions are safe on the iPad. Tell Jim, and use Export in History as a backup until he says it's fixed.

Things it doesn't do

These are known. No need to write them up.

  • No history between sessions. Each pen starts clean, so week-over-week trend happens in the spreadsheet, not in the app.
  • The four iPads don't talk to each other. Each one sends to the dashboard, and that is where the mounds come together.
  • In and Out are fixed to the grid, not flipped for left-handers.
  • PitchSafe is recorded, not enforced. Nothing warns you at a pitch count.
  • Nothing stops a coach unlocking a template and changing it. The app records that he did.
  • No warm-up / work / finish phases. The script is just an ordered list.
  • Freeform still expects a called spot. There's no way to log a pitch with no target at all.

What to send back

Run one full session, then tell me:

  • Whether one tap actually kept up, or whether you fell behind a quick pitcher.
  • Anything you tapped that didn't do what you expected.
  • Whether the call card is readable from where you stand.
  • How often you had to use Change the call — if it's constant, the script needs to be looser.
  • What you ended up writing on paper anyway. That one matters most.
